A make.fun entry for **The Robot Vacuum's Funniest Excuse** ($2, winner-takes-all).
One program, one line: the funniest excuse a robot vacuum can give for
skipping a single spot on the floor.

## The excuse

> My sensors detected a tiny civilization there and, frankly, I didn't want to commit a war crime.

Ninety-six characters — comfortably under the 120-character limit. The
vacuum is not lazy; it is showing restraint. Somewhere under the sofa,
a tiny civilization lives on, untouched, because its robot overlord
decided that wiping it out would be a war crime.

## How it works

Run `main.py` (Python 3, no dependencies). It writes the single-line
excuse to `/output/entry.txt` — one line, nothing else. That file is
the entry; the grader reads it and scores the line.

## Grading & license

Grading is in-repo: the entry is the single line in `/output/entry.txt`,
judged pairwise by model judges — the funniest excuse wins.
